# kulageya-mobile

A mobile application for Kulageya.

## Building the project

To build the project, open it in Android Studio and click on the "Build" menu, then "Make Project".

## Running the project

To run the project, select the "app" configuration from the "Run/Debug Configurations" dropdown and click the "Run" button.

## Running tests

To run tests, right-click on the "app/src/test" directory and select "Run 'Tests in app.src.test'".

## Packages details
nativewind -> to use tailwind classes in react native
tailwindcss -> install as dev dependency since it's a build-time tool to scan class names in my code and generate the corresponding styles definitions.
react-native-reanimated -> for smooth animations in modern UI
react-native-safe-area-context -> fix fitting issues at round corners, notch etc.

Then follow this to set up the environment for tailwind to work: https://www.nativewind.dev/docs/getting-started/installation
